# پنل ساری چین

پنل راست‌به‌چپ React و Vite با فونت وزیرمتن و تم روشن و تیره. منوی کاتالوگ سه فهرست محصولات، دسته‌بندی‌ها و برندها را نشان می‌دهد. پس از ورود با مدیر، می‌توانید رکورد اضافه کنید، نام و وضعیت را سریع ویرایش کنید، فرم کامل را باز کنید یا رکورد بدون وابستگی را حذف کنید. فرم کامل امکان انتخاب والد دسته و جستجو، انتخاب و ساخت تگ را دارد. حالت آزمایشی فقط خواندنی است.

## اجرا

به Node.js نسخه ۲۲٫۱۲ یا بالاتر نیاز دارید.

```bash
npm ci
npm run dev
```

پنل در [localhost:5173](http://localhost:5173) باز می‌شود. برای اتصال واقعی، بک‌اند را روی پورت ۳۰۰۱ اجرا کنید و با کاربر ساخته‌شده در آن وارد شوید. برای بک‌اند دیگر، `BACKEND_URL` را در فایل `.env` تنظیم کنید. مسیرهای پنل برای ورود و خواندن کاتالوگ از پراکسی `/api` عبور می‌کنند. حالت «مشاهده نسخه آزمایشی» بدون بک‌اند در دسترس است و داده‌های نمونه را با برچسب مشخص نمایش می‌دهد.

```bash
npm run build
npm run preview
```

برای میزبانی خروجی `dist/`، پراکسی ورودی `/api/*` را به بک‌اند متصل کنید و پیشوند `/api` را پیش از ارسال حذف کنید. توکن ورود در نشست همان تب ذخیره می‌شود.

## اعضا

منوی اعضا شامل کاربران پنل، مشتریان، تولیدکنندگان و ارائه‌دهندگان خدمات است. مدیر می‌تواند در هر فهرست جستجو کند و رکورد تازه بسازد یا ویرایش کند. شماره موبایل بین چهار گروه یکتا است. فرم کاربران پنل هنگام ساخت حساب، رمز ورود هم می‌گیرد.

## مواد اولیه

«معرفی ← مواد اولیه» دفترچه تماس تأمین‌کنندگان است. مدیر می‌تواند تگ‌های مشترک کاتالوگ، محدوده تماس، اولویت، شمار بازخورد و وضعیت انتشار را تنظیم کند. سایر حساب‌های واردشده فقط رکوردهای منتشرشده را می‌بینند.

## نقش‌ها و تنظیمات سازمانی

مدیریت از چرخ‌دنده سمت چپ نوار بالا، شعبه‌ها و پروفایل‌ها را در کشوی تنظیمات می‌سازد و ویرایش می‌کند. در کاربران پنل، مدیریت ادمین و ادمین شعبه کلاینت تعریف می‌کند. ادمین، کلاینت‌های شعبه خودش و ردیف معرفی ادمین‌های شعبه‌های دیگر را می‌بیند. کلاینت فقط منوی سفارش‌ها را دارد. دسترسی در بک‌اند نیز بررسی می‌شود.

فرم اعضا گزینه‌های استان و شهر را از API موقعیت می‌خواند. انتخاب استان، فهرست شهر را محدود می‌کند و جستجوی نام شهر در همان فهرست در دسترس است.
